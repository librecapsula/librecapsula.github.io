# LibreCapsula Wiki

Открытая документация по колонкам **VK Capsula** (VK Капсула): железо,
прошивки, джейлбрейк и инструменты. Ведётся сообществом
[LibreCapsula](https://github.com/librecapsula), правки принимаются через pull
request (см. [Как править вики](contributing.md)).

## Разделы

- :material-speaker: [**Устройства**](devices/index.md) - карточки
  устройств: Капсула, Капсула Мини, Капсула Нео, Mi Smart Speaker,
  Prestigio SmartVoice; железо, ревизии, прошивки.
- :material-chip: [**Железо**](hardware/index.md) - SoC, флеш,
  разделы, отладочный UART.
- :material-package-variant-closed: [**Прошивки**](firmware/index.md) -
  сток, OTA-пакеты, джейлбрейк.
- :material-tools: [**Инструменты**](tools/index.md) - capsula-jb,
  LibreRD и другие.

!!! warning "Дисклеймер"

    Всё здесь - результаты реверс-инженеринга сообщества, «как есть»,
    без каких-либо гарантий. Работа с режимами загрузки и флешем может
    лишить вас гарантии. Всегда начинайте с полного бэкапа (см.
    [Джейлбрейк](firmware/jailbreak.md)) и делайте всё на свой риск.

    Проект не связан с VK. Товарные знаки "ВК Капсула", "Маруся", и остальные - принадлежат их владельцам.
