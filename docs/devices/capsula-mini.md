# Капсула Мини

| Параметр | Значение |
|---|---|
| **Модели** | Capsula-mini-2, Capsula-mini-4, Capsula-mini-5, Capsula-mini-6 |
| **SoC** | Rockchip RK3308B / Amlogic A113X |
| **RAM** | DDR3 256 МБ |
| **Флеш** | NOR SPI / NAND Toshiba TC58NVG1S3HTA00, TSOP48, SLC 2 Гбит (~218 МБ) |
| **Wi-Fi/BT** | RTL8822CS / RTL8821CS / Amlogic TODO |
| **Сенсоры** | TTP224B-BSB |
| **Режимы USB** | Rockchip `2207:330d/330e/0006` / Amlogic `1b8e:c003` |

Компактная колонка семейства. Выпускалась в нескольких ревизиях на двух
платформах: Rockchip (RK3308B) и Amlogic
(A113X, Capsula-mini-6).

## Модели и ревизии

| Ревизия | Платформа | Особенности | Серийники |
|---|---|---|---|
| **Capsula-mini-2**  | RK3308B | Wi-Fi/BT - Realtek RTL8822CS |  **031XXXXXXXXXXXXX** |
| **Capsula-mini-4** | RK3308B | Wi-Fi/BT - Realtek RTL8821CS | **031XXXXXXXXXXXXX** |
| **Capsula-mini-6** | Amlogic A113X | | **034XXXXXXXXXXXXX** |

В реальности карта серийников сильно нестабильна и по ней сложно понять ревизию - карта постоянно менялась.
Первые два знака могут быть 01/03/05 - Rockchip Капсулы встречались в основном с 03.
Третий знак означает ревизию - если он больше 4 (5,6, или вообще буква) - это Amlogic.

Самый надёжный способ определить ревизию - посмотреть на процесс включения колонки.
**Rockchip** - загорается светодиодное кольцо и глазки одновременно
**Amlogic** - сначала загораются глазки, через несколько секунд загорается светодиодное кольцо.

## Особенности

- **UART** - стоковый fiq-debugger выведен на `serial-id = 0` (uart0,
  не разведён на плате) - лог ядра теряется после earlycon; чтобы
  видеть лог, консоль нужно переключить на отладочный UART правкой DTB
  (`serial-id = 2`, правка того же размера). Требуется правка DTS. Подробнее -
  [Отладочный UART](../hardware/uart.md).
- **USB** - из-за особенностей разводки платы Rockchip ревизий при питании от 5V   
  встроенный USB не поднимается без правки DTS (резисторный делитель на USB_DET выдаёт логическую единицу USB OTG режима только при питании от 9V).
  Иной способ - подпаивать GND, D+ и D- USB к плате к testpoint на плате (если смотреть на разъем подключения платы USB, сверху будет 4 тестпоинта, слева направо: GND, D-, D+, VCC 9/5V)
