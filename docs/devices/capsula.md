|---|---|

«Капсула» - большая умная колонка VK с голосовым ассистентом **Маруся**
на Rockchip RK3308. Наиболее изученная платформа проекта.

## Железо

### Аудиотракт

- **Микрофоны:** PDM-массив (узел `pdm@ff380000` включён). Звуковая
  карта стока - `vad-sound` = `pdm-i2s-dais` + `acodec` + `vad`.
- **Усилитель:** TI **TAS5731** на I2C `0x1a` (PDN на GPIO, mclk-fs
  256) - чип на шине, но его simple-audio-card в заводском DTS
  выключена; выход идёт через встроенный кодек.
- **Динамики:** 3″ woofer + tweeter; кроссовер цифровой, на SoC.
- **Bluetooth-звук:** карта `bluetooth-sound` (rk3308-pcm) включена -
  SCO/HFP через Wi-Fi/BT-модуль.


### Индикация, тач, сенсоры

| Устройство | Шина/адрес | Роль |
|---|---|---|
| IS31FL3236 (ISSI) | I2C `0x3c`, reset GPIO | LED-драйвер, 36 каналов - светящееся кольцо |
| AW2013 (Awinic) | I2C `0x45` | 3-канальный LED (led37/38/39) |
| HY461x | I2C `0x38`, irq/reset GPIO | ёмкостные сенсорные кнопки/панель, до 550×550 |
| BH1750 | I2C `0x23` | датчик освещённости |
| BH1730FVC | I2C `0x29` | датчик освещённости (второй) |
| STM32L01 | I2C `0x5a` | MCU RFID + калибровки LED |

### Питание и разъёмы

- Регуляторы (по DTS): `vcc_1v8`, `vcc_io`, `vcc_ddr`, `vccio_flash`,
  `vccio_sd`, `vcc_sd`, `vcc_phy`, `vcc_1v8_codec`; ядерное `vdd_core`
  - PWM (top-OPP 1296 МГц @ 1,30 В). WP# NAND подтянут вверх,
  VCCIO_FLASH = 3,3 В.
- **J3** (3-pin, UART2): не распаян разъём, но можно подпаяться.
- Адаптерная плата: кнопки Reset/Recovery, microUSB, питание.
- USB-порт - debug (OTG, gadget): MaskROM / loader / adb.

### Отладочный UART {#uart}

Консоль - **UART2_M1** (GPIO4_D2/D3, пады SDMMC_D2/D3), **1 500 000
8N1**, драйвер ядра - fiq-debugger (стоковый `serial-id = 2` - лог
ядра виден сразу).

| Точка | Назначение |
|---|---|
| TP50 / TP51 | UART2 RX / TX - консоль BootROM/U-Boot/ядра |
| TP5 | Recovery (линия ADC_KEY_IN1 = ADC_IN0, домен 1,8 В, подтяжка 10 кОм) |
| TP48 | FLASH_D0 - коротыш на GND (TP49) при старте = гарантированный MaskROM |
| TP49 | GND |

Общие приёмы - [Отладочный UART](../hardware/uart.md).

## Вход в режим загрузки {#download-mode}

Выключите питание, снимите нижнюю накладку, подключите micro-USB (OTG)
к компьютеру. Иголкой зажмите кнопку Recovery - **нижнее из двух
отверстий над micro-USB** (дальше от разъёма питания; электрически -
TP5/ADC_IN1) - и, удерживая, подайте питание; отпустите через
несколько секунд. Плата появляется как `2207:330d` (loader).

Короткое появление `2207:0006` при старте - это стоковый Linux-гаджет,
**не** режим загрузки. Как отличить MaskROM от загруженного usbplug -
см. [Отладочный UART](../hardware/uart.md#usbplug-vs-maskrom).

## Подарочные (gift) экземпляры

Часть подарочных больших Капсул подписана собственными (не production)
ключами: доступный prod-лоадер BootROM у них не принимает, поэтому
полный бэкап через лоадер невозможен. Работайте с такими платами
особенно аккуратно - восстановить содержимое флеша без дампа нечем.
Определить такую плату можно по серийному номеру - если он не начинается с **01**, то шанс попасть на таую колонку очень большой.
