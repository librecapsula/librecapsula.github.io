# OTA-пакеты

Стоковые прошивки распространяются OTA-пакетами с VK CDN; инструменты
проекта скачивают их автоматически (кеш - `ota/` или `cache/` в
каталоге инструмента).

```text
vcfw.vkcdn.ru/Capsule-14/44.90   # родной канал Capsule-14
vcfw.vkcdn.ru/Capsule-15/44.90   # Capsule-15
```

## Что внутри

OTA-пакет содержит образы платформы: boot.img (ядро + initramfs +
resource.img), vbmeta, system (squashfs), idblock и - главное для
инструментов - **подписанный лоадер** (usbplug).

- Лоадер, извлечённый из OTA Capsule-14, подходит **всем актуальным
  RK3308-прошивкам** Капсул: usbplug из OTA Capsule-14 и Capsule-15 -
  один и тот же бинарь (`rk3308_usbplug_v1.3`). Скачивается и кешируется
  автоматически.
- IDB пакета 44.90 несёт Boot1 **v1.33** (позднее поколение) - при
  прошивке полного пакета idblock перезаписывается на неё.
- Лоадер работает только в RAM (при бэкапе флеш не пишется); BootROM
  исполняет `db` **только с подписанным VK-лоадером родной платформы** -
  чужой/самоподписанный молча отвергается.

!!! note "BootROM принимает только «родной» лоадер"

    BootROM молча отвергает лоадер с чужой VRL-подписью: лоадер должен
    быть родным платформе (для Rockchip-плат проекта работает
    подписанный usbplug из OTA Capsule-14).

## Известные особенности стока (по rootfs 44.90)

- `S02mount-data.sh`: проверка/починка и монтирование `userdata`
  (ext2) в `/data`.
- `S23overlayfs.sh`: overlay (`lowerdir=/ upperdir=/data/overlay/upper
  workdir=/data/overlay/work`) + pivot_root - файлы из
  `userdata:/overlay/upper` оказываются в корне системы. Этот механизм
  использует [userspace-джейлбрейк](jailbreak.md).
- `S50usbdevice`: поднимает USB-гаджет ffs.adb и безусловно стартует
  `adbd &` - но в стоке 44.90 бинарника `adbd` в rootfs уже нет, поэтому
  гаджет мигает на секунду и умирает.
- Звуковая карта стока - `vad-sound` (PDM-микрофоны → встроенный
  кодек); драйверы и голосовой стек работают как в стоке и после обоих
  джейлбрейков.
