# Железо

Платформенная часть колонок Capsula: SoC, флеш-подсистема и отладочные
интерфейсы. Железо конкретных устройств (периферия, аудио, тестпоинты)
- в карточках раздела [Устройства](../devices/index.md).

- [SoC RK3308](rk3308.md) - основная платформа больших Капсул и мини на
  Rockchip; две ревизии кристалла; кратко про Amlogic A113X поздних мини.
- [Разделы флеша](partitions.md) - NAND-чип, SFTL, idblock, GPT-таблица
  с размерами, что чем подписано, маска 0xCC.
- [Отладочный UART](uart.md) - консоль, вход в rockusb/MaskROM,
  serial-id по платам.
